# 05-推理加速原理：TensorRT 与 SageAttention

> 2026-08 记录。以两个知名加速工具为例子，讲清楚"AI 推理加速"的整条原理链路，方便引申到其他工具。

## 起点：一次生成的时间花在哪

扩散模型生成一张图的耗时 ≈ **采样步数 × 每步 UNet 推理时间** + 固定开销（文本编码/VAE 解码）。所以加速只有三个杠杆：**① 砍步数**（蒸馏模型）**② 让每步更快**（编译/kernel 优化）**③ 少加载**（批处理）。TensorRT 和 SageAttention 都属于杠杆②，只是打法不同。

## 一、TensorRT：把模型"编译"成专属引擎

**它是什么**：英伟达官方的推理引擎编译器。类比：**TensorRT 是 gcc（编译器），引擎是可执行文件（编译产物）**。插件（如 ComfyUI-TensorRT）只是"编译器界面"，装好插件 ≠ 加速生效，必须先把模型编译成引擎。

**为什么每个引擎都"贵"且要现场构建**：引擎是硬绑定的，一次编译产物只适用于 `显卡型号 × 驱动/CUDA 版本 × 模型权重 × 分辨率` 的组合，任一变化都要重新编译。所以不存在"网上下载现成引擎"——官方不可能给每张卡发一个。

**构建流程三步**：
```
PyTorch 模型 ──①导出──> ONNX 中间格式 ──②引擎构建(GPU高负载)──> .engine 引擎文件 ──③部署(加载即用)
```
- ① 导出 ONNX：通用中间表示，跨框架
- ② 引擎构建：在目标 GPU 上实测每种运算的耗时，自动调优选最快实现（**这段用 GPU**，所以构建时显卡满载）
- ③ 部署：加载引擎直接跑，无需 PyTorch

**三大提速原理**（也是所有编译型加速器的通用原理）：
- **算子融合**：把"卷积+激活+归一化"等一串小运算合并成一个大运算。GPU 瓶颈是内存带宽，每少一次中间结果读写就快一分
- **自动选最优内核**：对每个运算跑几十种实现（不同 tile 尺寸、并行策略），选实测最快的
- **精度裁剪**：部分运算从 fp32 降到 fp16/int8，数据带宽减半，代价是精度略损（可控）

**我们踩的坑**：ComfyUI-TensorRT 插件停在 2024 年，调用的是旧版 PyTorch API（`force_patch_weights`），而服务器是 2026 年的 PyTorch 2.8 + ComfyUI 0.31——**工具不老，是版本组合逼我们只能用老插件**，导致 ONNX 导出阶段报 `aten::view` 算子错误，构建失败，最终放弃。

## 二、SageAttention：专攻注意力的 kernel 优化

**背景**：扩散模型里 **attention（注意力）计算占很大比重**，且复杂度随序列长度**平方增长**（QK^T 矩阵乘法）。优化 attention 是提速的关键抓手——FlashAttention、xFormers 都是这条路线。

**它做什么**：把 attention 里最大的两个矩阵运算用**低精度量化**跑：
```
原始: attention = softmax(Q·Kᵀ/√d) · V   （全程 fp16/fp32）
Sage: Q·Kᵀ 用 INT8 量化, P·V 用 FP8+FP16 累积   → 计算量减半, 显存带宽减半
```
用特殊写好的 CUDA/Triton kernel 执行，比 PyTorch 默认实现快得多，官方宣称 2-3 倍。

**为什么你的 2080Ti 用不了**：SageAttention 官方只为 **Ampere 架构及以上（sm80+，2020 年后的卡）** 编译 CUDA 内核；2080Ti 是 **Turing（sm75，2020 年前）**，官方内核不支持，只能退回 Triton 路径（等效第一代、收益打折、版本坑多）。**结论：加速工具和显卡架构强绑定，先查架构再选工具。**

## 三、引申：看懂任何加速工具的通用框架

任何推理加速工具，都可以从三个问题去理解：
- **它改什么**：改模型（蒸馏，砍步数）？改计算图（编译，融合算子）？改单算子实现（kernel，换算法）？
- **它在哪一步发力**：转换/编译阶段（一次性成本）还是运行阶段（每次受益）？
- **它绑定什么**：显卡架构（CUDA 版本）？模型权重？分辨率？——绑定越多，通用性越差，但优化空间越大

```
加速手段总谱系（按性价比排序）
─────────────────────────────────────────────
模型蒸馏 (LCM/Turbo)    改模型, 25→4步   性价比之王, 通用性最强
编译引擎 (TensorRT)     改计算图, 融合算子   提速30-50%, 绑定硬件
kernel优化 (SageAttention)  改单算子    提速2-3倍, 绑定架构+需适配
```

**给我们的启示**：2080Ti 上最稳的组合是"蒸馏模型（已用 LCM）+ torch 内置优化（fp16/FlashAttention）"，TensorRT 类编译引擎要等插件生态跟上新版 PyTorch 再考虑。
