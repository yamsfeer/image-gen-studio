# 升级 4090 迁移与部署计划

> 执行中（2026-08）。当前服务器：AutoDL RTX 2080 Ti 11G，升级到 4090 24G。本文是升级后的完整操作清单。

## 当前服务器状态（迁移前快照）

- 2080 Ti 11G，SSH 入口 `region-41.seetacloud.com:53278`（`.env` 中 SERVER_HOST/SSH_PORT）
- 模型全在 `/root/autodl-tmp`（数据盘，100G 用了 91G），ComfyUI/models 下是软链
- 服务：ComfyUI 0.31（:8188）、服务层 FastAPI（:8190）、nginx 反代（:8080 + Basic Auth）
- **注意**：llama-server（千问 27B）占着 8080 端口和 9.8G 显存，是另一个项目的服务，升级后要一起迁

## 迁移步骤（AutoDL 控制台）

- **数据盘**：同地区「跨实例拷贝数据」→「拷贝数据盘」，速度 100MB/s+，91G 约 15 分钟。源路径输 `*` 拷整个盘。
- **系统盘**：旧实例保存镜像，新实例用该镜像；或克隆实例（勾选数据盘）。
- **过渡**：旧实例先不释放，新实例跑通后再删。
- **省钱技巧**：等数据时旧实例可关到「无卡模式」（0.1 元/h，保留数据）。
