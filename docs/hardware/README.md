# 硬件 · 显存 · 多服务共存

> 2026-08 记录。起因：AutoDL 2080 Ti 上要同时跑 LLM（llama-server 千问 27B）+ 生图（ComfyUI），显存不够，经过一轮选型讨论沉淀下来的知识。
> 目标读者：未来的我（容易忘数字，只记得结论）。

## 一屏速览（核心结论）

**我们场景的显存需求**：LLM 27B Q4 常驻 9.8G + ComfyUI qwen-image 峰值 ~11G = **21G**。

- **显存 ≥ 24G 是硬门槛**，低于 24G 无法两个服务全速共存。
- **24G 是甜蜜点**：21G 需求装下还留 3G 余量（3090 / 4090 都行）。
- **16G 不够**（5070Ti）：只能牺牲一边（LLM 减层 / 生图降级 / LLM 换 8B）。
- **32G 宽裕**（5090）：还能留 11G 余量，一步到位但显存溢出。

**选型排序**（对"27B LLM + qwen-image 同时跑"）：云上 4090 ≈ 自购二手 4090 > 5090 > 3090 > 5070Ti。

**最终决定**：升级 AutoDL 云上 **4090 24G**（按量 ~1.9 元/h ≈ 1370 元/月，包月 1100-1400 元）。已确认执行，迁移见 [[04-升级4090迁移与部署计划]]。
