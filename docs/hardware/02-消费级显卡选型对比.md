# 消费级显卡选型对比

> 决策目标：一张卡同时跑 27B LLM + ComfyUI 生图。规格数据来自 2026 年市场实测/报价，价格会变，显存容量不会变。

## 规格全景表

| | 2080Ti（现役） | 3090 | 4090 | 5070 Ti | 5090 / 5090D |
|---|---|---|---|---|---|
| 架构 | Turing | Ampere | Ada Lovelace | Blackwell | Blackwell |
| **显存** | 11G GDDR6 | **24G** GDDR6X | **24G** GDDR6X | **16G** GDDR7 | **32G** GDDR7 |

## 关键结论

- **4090 和 3090 显存一样大（24G）**，决定共存能力的关键是显存容量，不是算力。4090 买的是"速度"不是"容量"。
- **4090 vs 3090 速度差**：生图约 2 倍（SDXL 实测 4.0 → 8.5 张/分），LLM 推理约 1.5 倍（带宽只高 8%，L2 缓存大 12 倍是主因）。
- **4090 vs 5070Ti**：算力 2.7 倍、显存多 50%、带宽高 12.5%——但最关键是 **5070Ti 16G 物理装不下 21G 需求**。5070Ti 赢在"全新有质保、便宜 4000-6000、功耗低 33%、FP4 未来潜力"，但显存硬伤补不回来。
- **"4090 是甜品卡"的说法**：传统显卡圈里 4090 是旗舰不是甜品；AI 圈说它是甜品，因为它是"24G 显存里算力最强的消费卡"，相对 A100/H100 便宜一两个数量级。对本地 LLM/绘图玩家成立。

## 显存需求账（为什么 24G 是门槛）

```
LLM 27B Q4（-ngl 40） 9.8G
qwen-image 峰值        ~11G（9.1G 权重 + CLIP/VAE/中间激活）
合计 ≈ 21G

24G（3090/4090）→ ✅ 留 3G 余量，全速共存
16G（5070Ti）   → ❌ 只能三选一降级：
                    ① LLM 减层（-ngl 40→12，~4G，27B 大部分跑 CPU 变慢）
                    ② 生图降级（放弃 qwen-image/z-image，只用 sd15/sdxl）
                    ③ LLM 换 8B 小模型（~5G，质量降一档）
32G（5090）     → ✅ 留 11G 余量，还能再塞别的
```

## 选型排序（对"27B LLM + qwen-image 同时跑"）

- **云上 4090** ≈ **自购二手 4090** > **5090** > **3090** > **5070Ti（不推荐，显存不够）**
- 云上 4090：省心（无矿卡风险/无电费/无硬件维护），按量 1370 元/月或包月 1100-1400 元
- 自购 4090：2023 年 10 月禁售后国行断供，只能二手（1.1-1.3 万），要防矿卡/翻新；价格因禁售反而坚挺
- 自购 5090D：一步到位但比 4090 贵 ~4000，且你只需 21G，32G 溢出
- **5070Ti 的适用场景**：能接受 LLM 降到 8B 级别，或生图只用轻量模型时，全新+质保+省电才成立

> 一句话：**显存 ≥ 24G 是硬门槛**，5070Ti 的 16G 过不了这道门槛。
