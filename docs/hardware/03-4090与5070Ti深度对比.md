# 4090 vs 5070 Ti 深度对比

> 为什么单独成篇：这是选型中最纠结的一组对比——"上一代旗舰二手卡" vs "新一代中端全新卡"，价格相近但代差巨大，容易只看参数表被新架构迷惑。完整记录规格、性能、显存、价格、功耗、生态六维度。

## 规格全景

| 维度 | RTX 4090 | RTX 5070 Ti | 胜负 |
|---|---|---|---|
| 架构 | Ada Lovelace（2022） | Blackwell（2025） | 5070Ti 新 |
| GPU 芯片 | AD102，16384 CUDA | GB203，8960 CUDA | 4090（核心多 83%） |
| **显存** | **24G** GDDR6X 384bit | **16G** GDDR7 256bit | **4090（多 50%，决定性）** |
| 显存带宽 | 1008 GB/s | 896 GB/s | 4090（+12.5%） |
| FP32 算力 | 82.6 TFLOPS | 43.9 TFLOPS | 4090（1.9 倍） |
| FP16 Tensor | ~330 TFLOPS | ~123.5 TFLOPS | **4090（2.7 倍）** |
| L2 缓存 | 72MB | 64MB | 4090 略优 |
| FP4 支持 | ❌ | ✅ | 5070Ti（未来潜力） |
| FP8 支持 | ✅ | ✅ | 平 |
| 接口 | PCIe 4.0 | PCIe 5.0 | 5070Ti |
| TDP | 450W | 300W | 5070Ti（低 33%） |
| 发布价 | 12999 元（2022） | 6299 元（2025） | — |

## 性能实测差距

- **游戏**：4090 快 20-30%（跑分基准 100% vs 77%），4K 下差距更明显。
- **AI 生图**（采样是计算密集）：4090 算力 2.7 倍 → 生图明显更快（SDXL 实测 4090 是 3090 的 2 倍，5070Ti 介于两者之间偏慢）。
- **LLM 推理**（解码是带宽瓶颈）：4090 带宽只高 12.5%，但算力余量大、L2 更大 → 单请求快 20-40%，并发/长上下文优势更大。

## 决定性差异：显存容量（这道题的死穴）

```
我们场景的需求：LLM 27B 常驻 9.8G + qwen-image 峰值 ~11G = 21G

4090 24G：  ✅ 21G < 24G，留 3G 余量 → 两个服务全速共存
5070Ti 16G：❌ 21G > 16G，物理装不下 → 必须降级一边
```

5070Ti 在 16G 下只有三条妥协路，条条都降级：

- **① LLM 减层**：`-ngl 40 → ~12`，显存降到 ~3-4G，27B 大部分层跑 CPU，聊天明显变慢。
- **② 生图降级**：放弃 qwen-image/z-image，只用 sd15/sdxl（2-6.5G），质量掉一档。
- **③ LLM 换小模型**：Qwen3-8B（~5G）→ 5+11=16G 刚好塞满，但 27B→8B 质量降级明显。

**5070Ti 唯一成立的条件**：接受 LLM 从 27B 降到 8B 级别，或生图只用轻量模型。否则就是"看起来新、实际不够用"。

## 价格与渠道（2026 年市场）

- **4090**：**只能二手**，1.1-1.3 万。2023 年 10 月美国禁令后国行断供，二手因禁售反而涨价坚挺。**风险：矿卡/翻新，水深**。
- **5070Ti**：**全新国行有货**，6100-8400 元，官方质保，无矿卡风险。
- 差价约 4000-6000 元——但 4090 多出来的钱买的是"显存 + 速度"，恰好是这道题最需要的两样。

## 功耗与电费（24h 常驻场景）

```
4090   450W → 整机 ~650W → ~15.6 度/天 ≈ 280 元/月电费
5070Ti 300W → 整机 ~500W → ~12 度/天   ≈ 220 元/月电费
（按 0.6 元/度估算，5070Ti 每月省 ~60 元）
```

## 架构代差与生态兼容

- **5070Ti（Blackwell）**：第 5 代 Tensor Core、FP4、PCIe 5.0。刚发布时需 CUDA 12.8+ / PyTorch 2.8+ / llama.cpp 最新版，有早期兼容性问题；**2026 年生态已适配**。
- **4090（Ada）**：生态最成熟，所有框架完美支持，教程/踩坑文档最多。FP8 对 qwen-image 这类新扩散模型友好。
- FP4 的"未来潜力"：前提是 ComfyUI/llama.cpp 真正支持 FP4 跑主流模型——目前价值有限，别为它买单。

## 结论

| 判断 | 内容 |
|---|---|
| 核心需求（27B LLM + qwen-image 全速共存） | **4090 完胜，5070Ti 显存不够直接出局** |
| 5070Ti 的诚实优点 | 全新+质保+非矿卡、便宜 4000-6000、功耗低 33%、FP4 未来潜力 |
| 5070Ti 的致命伤 | 16G 装不下 21G 需求，任何优点都补不回来 |
| 一句话 | **显存 ≥ 24G 是硬门槛，5070Ti 过不了这道门槛** |
